# SignalOps Frontend

SignalOps Frontend is a modern company intelligence dashboard built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui. It provides a clean and interactive interface for monitoring organizational health, team performance, operational risks, and AI-powered recommendations.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Recharts
- Framer Motion

Project is currently under development.

More features and documentation will be added as the project progresses.
